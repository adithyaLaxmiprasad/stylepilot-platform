# AI Outfit Generator – Frontend

A luxury-grade frontend prototype for an AI-powered outfit recommendation system.  
Built with **Next.js (App Router)** and **Tailwind CSS**, designed to feel premium, modern, and production-ready.

This frontend allows users to:
- Upload an image
- Select skin tone with visual guidance
- Choose occasion and preferred colors
- Add optional AI enhancement prompts
- Generate AI-powered outfit suggestions (backend-driven)

---

## ✨ Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (v3 – stable)
- **UI Philosophy:** Minimal, luxury, fashion-brand inspired
- **Bundler:** Stable Next.js default (no Turbopack)
